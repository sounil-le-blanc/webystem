Manifeste du web artisanal

← Retour au site

I. Le constat

Le web est devenu une industrie. Des usines à code. Des abonnements qui n'en finissent plus. Des sites qui pèsent 5 Mo pour afficher trois paragraphes et une photo.

On vous promet du "clé en main". On vous enferme dans des outils que vous ne maîtrisez pas. On vous facture chaque mois un service qui ne vous appartient jamais.

Ils ont industrialisé le web. Ils l'ont rendu obèse, lent, dépendant.

Nous disons : ça suffit.

II. Le retour à l'artisanat

Nous croyons qu'un site web est un objet artisanal. Comme une table. Comme une façade. Comme un outil de cordiste.

Un artisan choisit ses matériaux. Il les assemble avec soin. Il signe son travail. Il garantit sa durée.

Nous faisons pareil. Notre matériau, c'est le HTML, le CSS, le JavaScript. Les trois langages du web depuis 30 ans. Pas de framework qui périme en 18 mois. Pas de dépendance qui casse à la prochaine mise à jour. Du code brut, lisible, durable.

Un site artisanal pèse 50 Ko. Il se charge en une fraction de seconde. Il n'a pas besoin de maintenance. Il sera encore en ligne dans 10 ans.

III. La souveraineté

Un artisan ne garde pas les clés de votre maison. Il vous les rend quand le chantier est fini.

Nous appliquons ce principe au web. Le nom de domaine est à votre nom. Le code source vous est livré. Les emails, la base de données, tout est sur vos propres comptes. Vous êtes chez vous.

Si vous voulez changer de prestataire, vous prenez vos affaires et vous partez. En 5 minutes. Sans rien devoir.

Nous ne vendons pas des prisons. Nous construisons des maisons.

IV. La méthode low-tech

Nous utilisons l'IA comme un outil, pas comme un pilote automatique. Elle accélère le travail, mais c'est l'artisan qui décide, qui relit, qui assemble.

Nous détournons les services des géants de la tech pour offrir une infrastructure de niveau mondial à des prix dérisoires. Vercel, Supabase, Cloudflare, Resend, Stripe. Les meilleurs outils du monde, utilisés avec parcimonie, sans dépendance toxique.

Tout le reste, nous le faisons nous-mêmes. Le code. Le design. La logique. L'interface. L'expérience.

Pas d'usine à gaz. Pas de "solution digitale clé en main" qui vous enferme. Juste des outils simples, robustes, efficaces.

V. La transmission

Le savoir artisanal se partage, il ne se brevette pas.

Notre code est open-source. Notre méthode est documentée. Nous formons ceux qui veulent apprendre. Nous accueillons ceux qui veulent pratiquer.

Nous créons une guilde. Un réseau d'artisans du web qui partagent les mêmes principes : simplicité, durabilité, souveraineté.

Chacun est libre. Chacun est soutenu. Chacun enrichit l'écosystème.

VI. L'appel

Ce manifeste n'est pas un argument commercial. C'est une invitation.

Aux artisans, commerçants, indépendants qui en ont assez des solutions qui compliquent tout. Aux développeurs qui sentent que l'industrie est allée trop loin. Aux curieux qui veulent comprendre comment on peut faire mieux avec moins.

Rejoignez-nous. Apprenez la méthode. Construisez vos outils. Reprenez le contrôle.

Le web artisanal renaît. Et cette fois, il ne disparaîtra pas.
